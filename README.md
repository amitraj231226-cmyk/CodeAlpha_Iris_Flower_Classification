Iris Flower Classification

About the Project

This project is developed as part of the CodeAlpha Data Science Internship.

The objective of this project is to build a Machine Learning classification model that can classify Iris flowers into three species:

- Setosa
- Versicolor
- Virginica

The classification is performed using flower measurements such as sepal length, sepal width, petal length, and petal width.

Dataset

The project uses the Iris dataset available through Scikit-learn.

The dataset contains four input features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The target variable represents the three Iris flower species.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- VS Code

Machine Learning Model

A Decision Tree Classifier was used to classify the Iris flower species.

The dataset was divided into:

- 80% Training Data
- 20% Testing Data

The model was trained using the training dataset and evaluated using the testing dataset.

Model Performance

The Decision Tree Classifier achieved:

Accuracy: 93.33%

The model was further evaluated using:

- Classification Report
- Confusion Matrix
- Feature Importance
